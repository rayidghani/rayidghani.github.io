# rayidghani.github.io

A multi-page personal website starter inspired by the structure and tone of [rayidghani.com](https://www.rayidghani.com/).

## Files

- `index.html` – homepage with biography and links to the major site sections
- `projects-tools.html` – dedicated page for projects, tools, initiatives, and collaborations
- `research.html` – dedicated page for research themes and agenda
- `publications.html` – dedicated page for papers, reports, essays, and talks
- `teaching.html` – dedicated page for courses, mentoring, and teaching philosophy
- `styles.css` – shared layout, typography, and responsive styling across all pages

## Customize it

Update the placeholder content in the HTML files with your:

- name and title
- biography and affiliations
- projects, tools, and collaborations
- research themes and current agenda
- publications, writing, and talks
- teaching materials and courses
- contact links and email

Then publish the repository with GitHub Pages to make the site live.
