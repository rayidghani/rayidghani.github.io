# rayidghani.github.io

A single-page personal website starter inspired by the structure and tone of [rayidghani.com](https://www.rayidghani.com/).

## Files

- `index.html` – main content and page structure
- `styles.css` – layout, typography, and responsive styling

## Customize it

Update the placeholder content in `index.html` with your:

- name and title
- biography
- projects or selected work
- publications, writing, or talks
- contact links and email

Then publish the repository with GitHub Pages to make the site live.
